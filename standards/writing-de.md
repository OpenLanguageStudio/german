# Writing rules: German

These rules apply to the German coursebook only. They add to the global writing rules in the
engine (`docs/reference/writing-rules.md`, `OL-W1` onwards), which apply first. IDs follow the
global scheme: `DE-W<n>`, never renumbered or reused. A rule that narrows a global rule names
it.

**DE-W1. Sie and du in tabs.** Narrows OL-W8. Phrases that exist in a *Sie* and a *du* version
are shown in a tab set labelled `Formal (Sie)` and `Informal (du)`, formal first, with an
examples block in each tab. Reason: the two registers appear in the same place on every page.
