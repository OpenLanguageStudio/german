# Writing rules: German

Rules for the German coursebook only. They add to the global writing rules in the engine
(`docs/reference/writing-rules.md`, `OL-W1` onwards), which every page follows first. The ID
scheme is the same: cite `DE-W<n>`, never renumber or reuse an ID, mark a retired rule
*Retired* with the date. A rule that narrows a global rule names it.

**DE-W1. Sie and du in tabs, labelled `Formal (Sie)` and `Informal (du)`.** Narrows OL-W8.
Wherever the same phrases come in a *Sie* and a *du* version, show both in a tab set with
those two labels, formal first, with an examples block in each tab. Why: readers learn to
expect the two registers in the same place on every page.

**DE-W2. Run the lexicon check on every page.** Articles, plurals and spellings of German
words in tables and examples are checked against the course lexicon before review. Fix every
error and look at every query. Why: a wrong gender in a table teaches the wrong word.
