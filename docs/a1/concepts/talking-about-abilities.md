# Talking about abilities

One modal verb does nearly all the work here, so this concept is mostly about fluency with *können*. What varies is the small words around it, the ones that grade an ability from barely to very well, and the phrasing for a skill that is still missing.

## When to use it

- Answering *Was kannst du gut?* about sports, music, languages
- Saying honestly what you cannot do, or not yet
- Talking about children's and other people's skills

## Key phrases

| German | English | Notes |
|---|---|---|
| Ich kann (gut) schwimmen. | I can swim (well). | |
| Ich kann nicht singen. | I can't sing. | |
| ein bisschen | a little | the honest qualifier |
| schon / noch nicht | already / not yet | progress words |
| Kannst du ...? | Can you ...? | |
| Was kannst du gut? | What are you good at? | |

## Saying what you can do

*Können* opens the bracket, the skill closes it as an infinitive. Grade it with *gut*, *sehr gut*, or *ein bisschen*.

**Examples:**

:::{div} ol-examples
Ich kann gut **schwimmen**.
: I can swim well.

Ich kann ein bisschen Deutsch **sprechen**.
: I can speak a little German.

Sie kann Auto **fahren**.
: She can drive.
:::

## Saying what you cannot do

*Nicht* slots in before the closing infinitive. For skills still on the way, *noch nicht* (not yet) is kinder and often truer; its opposite *schon* (already) celebrates progress.

**Examples:**

:::{div} ol-examples
Ich kann **nicht** singen.
: I can't sing.

Mein Sohn kann **noch nicht** schreiben.
: My son can't write yet.

Meine Tochter kann **schon** lesen.
: My daughter can already read.
:::

## Asking others

*Kannst du ...?* and *Können Sie ...?* ask about ability; *Was kannst du gut?* opens the topic wide.

**Examples:**

:::{div} ol-examples
Kannst du Gitarre spielen?
: Can you play the guitar?

Nein, aber ich kann Klavier spielen.
: No, but I can play the piano.
:::

## Summary

:::{admonition} Key points
:class: note

- *können* + infinitive at the end covers every ability sentence.
- Grade skills with *gut, sehr gut, ein bisschen*.
- *noch nicht* = not yet, *schon* = already: the progress pair.
- Instruments and languages take no article: *Klavier spielen, Deutsch sprechen*.
:::

:::{admonition} Common mistakes
:class: caution

- *\*Ich kann schwimmen gut.* → Ich kann **gut schwimmen**. (gut before the infinitive)
- *\*Ich kann nicht noch schreiben.* → Ich kann **noch nicht** schreiben. (fixed order)
- *\*Ich kann die Gitarre spielen.* → Ich kann **Gitarre** spielen. (no article for instruments)
:::
